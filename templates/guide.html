How to use THE SOLVER

Write any math problem — the engine understands plain text. Here's the full syntax guide.

◆
I Getting Started

You don't need special syntax. Just type your problem the way you'd say it, and the engine figures out the rest.

  • Use plain text — no LaTeX required from you.
  • Use ^ for powers: x^2 means x².
  • Use * or nothing for multiplication: 2x or 2*x.
  • Use the 123 tab if you don't want to type symbols.
  • Use the Enter key or press the big white button.
Tip: Type in English or Persian. Math symbols are the same.

2 Equations

Write the equation as it is. The engine finds the value of the unknown.

Linear Equations

2x + 5 = 15
→
x = 5

Quadratic Equations

x^2 - 5x + 6 = 0
→
x = 2 or x = 3

Systems of Equations

2x + y = 10 and x - y = 2
→
x = 4, y = 2

Cubic & Higher

x^3 - 6x^2 + 11x - 6 = 0
→
x = 1, 2, or 3

Inequalities

2x + 3 < 11
→
x < 4
3 Derivatives

Ask for a derivative in plain English or with symbolic notation.

derivative of x^3
→
3x²
d/dx (sin(x) * x^2)
→
2x·sin(x) + x²·cos(x)
f'(x) where f(x) = ln(x)
→
1/x
Tip: You can also write diff(x^3), ∂/∂x (x^2 y), or مشتق x^2.
4 Integrals

Write integral or ∫. For definite integrals, add the bounds.

Indefinite

→

Definite

integral of x^2 from 0 to 1
→
1/3
∫₀^π sin(x) dx

Tip: Use the Calculus tab in the keyboard for the ∫ symbol.

6 Differential Equations

Write the equation in plain form. The engine will find the general solution.

dy/dx = 2x
→
y = x² + C
y' + y = 0
→
y = C·e⁻ˣ
y'' - 3y' + 2y = 0
→
y = C₁·eˣ + C₂·e²ˣ
Tip: For second derivatives, use y'' or d^2y/dx^2.

11 Tips & Tricks
  • Use the keyboard if you don't want to type symbols. The 123 tab is a full numeric pad.
  • Instant answers for arithmetic come from the calculator — no AI wasted.
  • Repeat questions are cached for 24 hours — they return instantly.
  • Try different engines — some are better at calculus, others at logic.
  • Share answers with the ↗ button — it copies a link with the question inside.
  • Graph functions — write y = x^2 and the graph appears automatically.
